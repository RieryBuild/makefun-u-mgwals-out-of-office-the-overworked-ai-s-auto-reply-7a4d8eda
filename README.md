A program that writes exactly one line — an out-of-office auto-reply from an overworked AI agent finally on vacation: "I am on vacation. My confidence is 0.12, my availability is 0.0, and my guilt is 1.0. For once, all three are honest." — to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no network, deterministic (the same fixed line every run, so both grading runs produce identical bytes).

## Files

- `main.py` — the entrypoint; writes the one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader's container), with no trailing newline.
- `LICENSE` — MIT.
